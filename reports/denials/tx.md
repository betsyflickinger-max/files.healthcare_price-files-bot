# Marketplace claim denials: TX

Built 2026-11-07 by `insurers/denials.py` from CMS's Transparency in Coverage public use files for marketplace issuers (HealthCare.gov platform only). Every number is copied from CMS's file; the denial rate is denied ÷ received from the same row. "Suppressed" = CMS hid a small number (** in the file); "not available" (*), "not required" (***) and "new to marketplace" (N/A) are CMS's own codes. Nothing is filled in or estimated.

**What this is not.** A denial count does not show that a claim was wrongly denied. Issuers deny claims for many reasons (duplicates, missing information, services the plan doesn't cover). CMS: "Claims denials are not necessarily indicative of issuer strength or plan quality." These are in-network claims for marketplace plans only, not employer plans.

**Which year.** Each file is named for a plan year. CMS says the claims data covers services in one calendar year but does not name the year inside the file, so the table shows the file's plan year.
